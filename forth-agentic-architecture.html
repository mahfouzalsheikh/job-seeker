05 · Orchestration06 / 15

A run is a resumable state machine

Autonomy happens between clear gates.

01 · Trigger

Event arrives

User message, schedule, source refresh, or pipeline change.

02 · Context

Retrieve narrowly

Relevant profile facts, job version, policies, and prior decisions.

03 · Act

Call typed tools

One bounded workflow with idempotency, budgets, and structured output.

04 · Gate

Ask when it matters

New facts, apply decisions, unsupported claims, messages, final artifacts.

05 · Commit

Save + explain

Persist outcome, provenance, audit event, and suggested next action.

Retryable

Every tool call has a stable key and can safely resume after failure.

Observable

Run status streams over the existing realtime channel.

Interruptible

The user can pause schedules, cancel runs, or change intent.

08 · Scoring09 / 15

Ship vertical value, then increase autonomy

A pragmatic four-phase path.

Phase 1Weeks 1–3 · Trust core

Make profile + scoring reliable

  • Candidate profile & preference schema
  • Requirement-level job extraction
  • Hard filters + decomposed score
  • Evidence citations and eval dataset
Phase 2Weeks 4–6 · Daily loop

Source and triage jobs

  • Source-run model + connector contract
  • Greenhouse / Lever / Ashby adapters
  • Freshness, dedupe, review queue
  • Daily digest and feedback capture
Phase 3Weeks 7–9 · Apply loop

Prepare polished materials

  • Approval-driven pipeline transitions
  • Résumé + cover-letter change plans
  • Claim validator and diff review
  • HTML templates + Gotenberg PDFs
Phase 4Weeks 10–12 · Agent layer

Unify through conversation

  • Agent runs, steps, and approvals
  • Concierge chat and typed tools
  • Scheduled workflows + recovery
  • Outcome analytics and calibration
14 · Recommendation15 / 15

What to do next

Build the decision loop before the agent spectacle.

The fastest path is to deepen the existing domain model, make matching trustworthy, and ship one end-to-end workflow: new job → explained match → user approval → tailored résumé + cover letter → PDF → tracked application.
